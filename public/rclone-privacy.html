Privacy Policy: rclone (personal OAuth client)

Last updated: November 22, 2026

This Google OAuth client, named "rclone", is used only by the owner of this site, Hazel, for personal file transfers to her own Google Drive with the open-source tool rclone. It is not offered to the public.

The client requests only the https://www.googleapis.com/auth/drive.file scope, which allows access only to files that rclone itself creates or opens.

No data is collected, stored on any server, sold, or shared with third parties. Authorization tokens stay on the user's own computer in the local rclone configuration file. Access can be revoked at any time at myaccount.google.com/permissions.
